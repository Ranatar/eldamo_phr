# Eldamo — фонетический атлас Quenya и Sindarin

Звуковые изменения квенья и синдарина (с их «средними» вариантами Qenya/Noldorin) по данным лексикона
[Eldamo](https://eldamo.org) Пола Страка: фонетические правила, их засвидетельствованные применения к
конкретным словам, граф переходов между звуками и цепочки изменений с оценкой по свидетельствам и
хронологии. Результат — автономный атлас в одном HTML-файле, обозреватель полного корпуса и данные в JSON.

- Атлас: `app/index.html` (после сборки), опубликованная версия — GitHub Pages репозитория.
- Обозреватель корпуса: `app/corpus.html`.
- Данные ветвей: `branches/<ветвь>/data/*.json`, читаемый каталог правил: `branches/<ветвь>/catalog.md`.
- Аудит сборки: `reports/audit.md`.

## Источник

Единственный вход — модель данных Eldamo `eldamo-data.xml`, сжатая в
`source/eldamo-data-0.8.13.xml.xz` (4 МБ). Контрольные суммы XML и исходного релизного архива — в
`source/SOURCE.json`; сборка сверяет их и читает XML строго как UTF-8. Остальной сайт Eldamo не нужен и
не распространяется.

Обновление на новую версию Eldamo:

```
python scripts/import_eldamo_release.py eldamo-X.Y.Z.zip     # или путь к eldamo-data.xml
python scripts/build.py
```

## Сборка

Нужен только Python ≥ 3.8 (подходит последний Python для Windows 7), без сторонних пакетов:

```
python scripts/build.py              # данные, каталоги, экспорт, атлас, отчёт и все тесты
python scripts/build.py --no-browser # без браузерного теста
python scripts/build.py --no-tests   # только сборка
```

Сборка занимает 5–10 секунд и детерминирована: на Python 3.8 в локали cp1251 и на Python 3.13 в UTF-8
получаются побайтово одинаковые файлы (все файлы пишутся в UTF-8 с `\n`, атомарно).

Браузерный тест (`tests/test_browser.py`) необязателен: ему нужен Playwright
(`pip install playwright && python -m playwright install chromium`), и он пропускается, если Playwright
или браузера нет. `ELDAMO_CHROMIUM=/путь/к/chrome` задаёт свой браузер, `ELDAMO_REQUIRE_BROWSER=1`
превращает пропуск в ошибку.

## Как получаются данные

Конфигурация ветвей — `shared/languages.py`:

| ветвь | поздняя концепция | средняя концепция |
|---|---|---|
| quenya | ✶ Primitive → AQ. Ancient Quenya → Q. Quenya | ᴹ✶ → ᴹAQ. → ᴹQ. |
| sindarin | ✶ → AT. Ancient Telerin → OS. Old Sindarin → S. Sindarin | ᴹ✶ → ON. Old Noldorin → N. Noldorin |

1. **Правила** (`shared/model.py`) — страницы `<word speech="phonetic-rule">` языков ветви: название,
   общая формула (`@from > @rule`), порядок `@order`, связи `<before>`, заметки, подформулы `<rule>`.
   Правила, удалённые Толкином (`mark="-"`), исключаются.
2. **Деривации** — каждый `<deriv>` с шагами `<rule-example>`: последовательность применения правил к
   слову с промежуточными формами, как её приводит Eldamo со ссылкой на источник. Шаг связан с
   подформулой по тройке «язык, from, rule» (две тройки в Eldamo 0.8.13 повторяются на одной странице —
   шаг относится к первой). Подформула получает язык и ступень из собственного `l`. Деривации, отвергнутые
   Толкином, помечаются и не считаются свидетельствами. Праэльфийские шаги общие для обеих ветвей; в атласе по умолчанию
   показываются слова своей ветви.
3. **Проверка формул** (`shared/interpreter.py`) — каждый шаг проигрывается: формула применяется к
   предыдущей форме, результат сравнивается со следующей. Интерпретатор реализует нотацию из
   `general/phonetic-descriptions.html` Eldamo (классы `V C X S`, долгота, наборы `{…}` с `|`, индексы,
   `ø`, позиции через дефис, применение ко всем позициям сразу) и недокументированные, но используемые
   `C*` и знаки ударения. Неизвестная нотация даёт явный статус `unsupported`, а не тихий «не совпало».
   Соглашения сравнения: две одинаковые краткие гласные равны долгой (`laa` = `lā`), ударение не
   учитывается, при `CCC > CC` выпадает средний согласный, при `-CC > -C` — последний. Шаги с `+`
   (граница морфем) проверить нельзя — в формах граница не записана, они получают `unsupported`.
   Шаги по неизменным подформулам-исключениям и по удалённым правилам в процент не входят.
4. **Граф** (`shared/graph.py`) — рёбра из литеральных подформул (`a > b`, включая исчезновение `a > ø`).
   Ребро сохраняет условие своего правила: общую формулу с классами и исключения — неизменные подформулы
   вида `mb > mb` на странице правила («voiced stops became spirants *except after nasals*»), а также
   условие ударения. Узлы — звуки без знаков ударения и краткости (`ˌau` и `au` — один узел).
   Подформулы с классами и контекстом, а также подформулы языков вне ветви в граф не входят.
5. **Цепочки** — пути из 2–3 рёбер одного периода в хронологическом порядке: следующая языковая ступень,
   либо внутри языка порядок Eldamo (`order`, `<before>`; меньший `order` — более раннее правило, это
   подтверждают все 413 связей `<before>` с известным порядком). Пути, которым хронология Eldamo
   противоречит, отбрасываются (их число — в отчёте). Свидетель — шаг деривации, который формула
   воспроизводит и который меняет форму. Оценки:

   | | значение |
   |---|---|
   | **A** | шаги применены в этом порядке в одной засвидетельствованной деривации |
   | **B** | у каждого шага есть воспроизведённые засвидетельствованные примеры, порядок подтверждён |
   | **C** | у каждого шага есть такие примеры, но порядок части шагов не установлен |
   | **D** | у какого-то шага нет воспроизведённых засвидетельствованных примеров |

## Что умеет атлас

- выбор ветви и концепции; состояние в адресе (`#quenya?era=late&from=b&to=v`), работает «назад»;
- выбор звука по сетке МФА, построенной из инвентаря фонем ветви, или сочетания из графа;
- поиск путей между звуками с учётом хронологии Eldamo, фильтрами «только засвидетельствованные шаги» и
  «без условных правил»; для каждого шага — правило со ссылкой, условие, примеры слов; отметка, если
  путь засвидетельствован целиком;
- деревья развития и происхождения звука со схемой (сплошные линии — засвидетельствованные переходы);
- все подформулы со звуком или сочетанием, с общей формулой и долей воспроизведённых примеров;
- атлас цепочек с оценками A–D и словами-свидетелями;
- поиск по засвидетельствованным деривациям (слово, форма, значение, правило) с проверкой каждого шага
  и ссылками на статью Eldamo и точное место источника;
- светлая и тёмная тема, работа без сети, мобильная вёрстка.

## Структура

```
source/            eldamo-data-*.xml.xz и SOURCE.json — единственный вход
shared/            source, languages, model, interpreter, formula, graph, pipeline,
                   ipa, catalog, exports, app, report, io
scripts/build.py   полная сборка и тесты
scripts/import_eldamo_release.py   импорт новой версии Eldamo
app/               template.html, runtime.js, styles.css, corpus_template.html → index.html, corpus.html
branches/<ветвь>/  data/{phonemes,rules,pairs,derivations,edges,chains,summary}.json, catalog.md
exports/           canonical.json (всё одним файлом), atlas.graphml (граф для Gephi/yEd)
reports/           audit.md, audit.json — охват, проверка шагов, невоспроизведённые шаги
tests/             поведение интерпретатора, инварианты против XML, граф, выходные файлы, браузер
docs/              переход с HTML-конвейера (MIGRATION.md), наследие прежних этапов (legacy/),
                   прежние README и отчёты (history/)
```

Сгенерированные HTML и `exports/` в git не хранятся: их собирает `scripts/build.py`, а для GitHub Pages —
workflow `.github/workflows/pages.yml`. Данные ветвей, каталоги и отчёт хранятся, чтобы изменения между
версиями Eldamo и кода были видны в диффах.

## Ограничения

- Граф связывает только литеральные подформулы. Правила с классами (`V{ptk} > V{bdg}`) применимы к
  словам, но не дают рёбер «звук → звук»; они видны в правилах звука и в деривациях.
- Цепочка с оценкой A засвидетельствована в слове, но связность сегментов между шагами не проверяется:
  засвидетельствовано, что оба правила применены к слову в этом порядке.
- Знаки ударения в формулах игнорируются (ударение в формах не записано), поэтому такие правила могут
  применяться шире, чем у Страка.
- Около 6% засвидетельствованных шагов формулы не воспроизводят: в Eldamo встречаются шаги, где в одной
  записи совмещено несколько изменений, повторы формы, позиционные правила внутри сложных слов, а в
  квенийских формах иногда пишется `y` вместо `j`. Полный список — `reports/audit.json`, разбор по
  правилам — `reports/audit.md`.
- Порядок Eldamo (`order`) есть у 211 из 251 правил квенья и у 263 из 303 синдарина; где его нет,
  переход внутри одной ступени считается неустановленным (оценка C).
