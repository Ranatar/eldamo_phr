# Eldamo: интерактивный атлас фонетических цепочек

Расширение приложения на основе Eldamo 0.8.13.

## Использование

- `app/built.html` — автономное приложение, откройте в браузере.
- `app/index.html` — модульный вариант. Для браузеров с ограничениями `file:` запускайте через локальный HTTP-сервер из папки `app` (`python -m http.server 8000`).
- Обычные кнопки поиска пути и показа правил сохранены.
- Новый раздел **Атлас цепочек** содержит отдельные кнопки **Все цепочки**, **Развитие исходного звука**, **Происхождение конечного звука**. Использует текущие выбранные фонемы/сочетания, период, глубину и фильтр примеров.
- Для новых структурных цепочек статус «не оценена» не означает категорию U (недостаточно данных).

## Воспроизведение

Из корня архива:

```bash
python development/add_atlas.py
python development/build_standalone.py
python development/test_atlas.py
```

Для тестов нужен Playwright Python и Chromium. `add_atlas.py` читает `data/eldamo_critical_101_atlas.csv` и `data/eldamo_v3_rebuilt_structural_graph.csv`.

## Ограничения

Деревья построены на 601 атомарном переходе, не на исполнении всех контекстных фонетических правил в произвольных словах. Поиск ограничивает число состояний и число отображаемых результатов; при усечении это отражается в интерфейсе. Исторические категории перенесены из предыдущего исследовательского атласа, не переоценивались автоматически. Наличие стрелок не подтверждает полную историческую цепочку.

## Оценка дополнительных 38 цепочек

Все 38 записей теперь имеют индивидуальную консервативную категорию (11 D, 27 U) и ссылки на правила; результаты и методика: `reports/eldamo_38_chain_assessment.md`, `data/eldamo_38_chain_assessment.csv`. Скрипт: `development/assess_38.py`. Эти оценки не подтверждают полноту исторической цепи; заново сгенерированные интерактивным поиском пути оцениваются отдельно.
