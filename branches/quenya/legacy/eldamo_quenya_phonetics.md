# Eldamo: фонетические правила Quenya и Ancient Quenya без маркера Early Qenya

**Источник:** Eldamo, Paul Strack, версия 0.8.13 (31 мая 2026).

**Статус: частичная сверка по отдельным звукам.** Ниже приведён полный *общий индекс* правил двух языков, но он не равнозначен полному набору записей на страницах каждого звука. По отдельным страницам непосредственно проверены только Q. [p], Q. [t], Q. [i] и AQ. [p]. Поэтому итоговый полный перечень, разбитый по всем звукам и отфильтрованный построчно, **пока не установлен**. Для непроверенных звуков никакие записи не приписываются им как проверенные.

## Критерии

По [терминологии Eldamo](https://eldamo.org/general/terminology-and-notations.html), `ᴱQ.` — **Early Qenya**, `ᴹQ.` — Middle Quenya, `Q.` — Late Quenya, `AQ.` — Ancient Quenya. На странице звука нужно отдельно отбирать строки блока **Phonetic Development**, у которых нет метки `ᴱQ.`; наличие на той же странице *другого* блока `ᴱQ.` не исключает подходящие строки. Примитивная форма `✶` также не тождественна `ᴱQ.`. Правила могут повторяться под несколькими звуками и в нескольких периодах; для полной выгрузки нужно сохранить звук, маркер, преобразование, ссылку и источник.

## Пробелы в проверке

Общие индексы содержат 47 и 46 записей соответственно, однако отдельные страницы звуков включают также позиции, отсутствующие в общих индексах, например `[no change]`, примитивные `✶` и переходы среднего периода. Полное исполнение запроса требует просмотра **всех** ссылок из таблиц `Phonemes` обоих языков и переписи всех строк `Phonetic Development`, кроме `ᴱQ.`. Текущую версию нельзя использовать как исчерпывающий фонемный указатель.

## Воспроизводимое получение полного перечня

Для полной постраничной выгрузки подготовлен отдельный скрипт [`eldamo_full_catalog.py`](eldamo_full_catalog.py). Он обходит таблицы **Phonemes** обоих языков, открывает каждую звуковую карточку, извлекает строки **Phonetic Development**, исключает `ᴱQ.`, сохраняет остальные маркеры, преобразования и ссылки, а также записывает итоговый `eldamo_quenya_ancient_quenya_full.md`.

Запуск в каталоге с файлом скрипта (требуется сетевое подключение к eldamo.org):

```bash
python -m pip install requests beautifulsoup4
python eldamo_full_catalog.py
```

**Важное ограничение:** выполнить этот скрипт в текущей вычислительной среде не удалось, поскольку исходящие сетевые обращения из неё заблокированы. Поэтому это руководство и подготовленная программа, а **не подтверждение выполнения полной выгрузки**. До успешного запуска и проверки результата текущий документ остаётся неполным в части карточек отдельных звуков.
