# Eldamo Sindarin / Noldorin — отдельный фонетический атлас

Источник: Eldamo 0.8.13, архив eldamo-0.8.13.zip.

Поздняя линия: Primitive Elvish → Ancient Telerin → Old Sindarin → Sindarin.
Средняя линия: Middle Primitive Elvish → Old Noldorin → Noldorin.

Аманский Telerin и Middle Telerin исключены. Разные исторические концепции никогда не смешиваются при поиске.

## Выходные файлы

- `app/standalone.html` — автономная версия
- `app/index.html`, `styles.css`, `app.js`, `data.js`, `chains.js` — модульная версия
- `app/rules.json` — каталог правил по звукам
- `app/edges.json` — осторожная атомарная проекция
- `app/chains.json` — **структурные, ещё не оценённые** цепочки
- `catalog/sindarin_phonetic_catalog.md` — полный каталог по звукам
- `data/rule_inventory.csv` — реестр всех уникальных формул
- `scripts/build_sindarin.py` — повторная сборка

## Проверки

Обнаружено 61 разных обозначений фонем; 454 вхождений, 440 объединённых записей, 230 атомарных переходов, 118 структурных цепочек. Ошибок чтения: 0.

**Доказательность:** цепочки категории U, поскольку наличие сочетаемых атомарных правил не является доказательством их последовательной исторической применимости. Применимость окружений и хронология по заметкам ещё не верифицированы для всех путей. Это не перенос 139 оценок Quenya.

Страница применяет ограничения на период и порядок ступеней. Результаты поиска — гипотезы, а не полностью доказанные этимологии.
