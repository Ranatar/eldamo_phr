# Переход с HTML-карточек на eldamo-data.xml

До этой версии («v10») правила извлекались из HTML-страниц сайта Eldamo — из таблиц
«Phonetic Development» на фонемных карточках. Разбор репозитория выявил у этого способа три
принципиальных дефекта. Все три снимает переход на модель данных `eldamo-data.xml`, из которой Eldamo
сам генерирует эти страницы.

## Что было не так

1. **Правила чужих языков.** Регулярное выражение маркера языка не знало `Ilk.`, `Dan.`, `Van.`,
   `Lin.`. Строка такого правила наследовала маркер и название *предыдущей* строки, а URL брала свой.
   Так в корпус попали 75 записей (38 страниц) у квенья и 41 запись (24 страницы) у синдарина:
   илькоринские, данские, ваньярские и линдарские правила под чужими названиями. Например, `Van. [mm],
   [nn] became [mb], [nd]` значилось как `AQ. [z] assimilated to following [m], [n]`. На эти записи
   опирались 52 и 31 ребро графа, 67 и 30 цепочек.
2. **Зеркальные дубли.** Одно и то же правило с карточки источника (`pt > ɸt`) и с карточки результата
   (`ɸt < pt`) хранилось дважды. Из 861 и 570 «правил» различных по ключу (период, маркер, откуда, куда,
   URL, название) было 496 и 345.
3. **Неполный охват.** Карточки — производное представление: до многих правил с них не дойти.
   Использовано было 139 из 252 страниц правил квенья и 115 из 306 синдарина. В корпусе не было,
   например, синдаринской лениции `S. voiceless stops voiced after vowels`.

Кроме того, хронология Eldamo (`order`, `<before>`) не извлекалась вовсе. Позиционные цепочки из-за
ошибки сравнения дефисов всегда получали низшую оценку. На Python 3.8 интерпретатор тихо обнулял
проверку примеров (`str.removeprefix`).

## Что стало

| | квенья: было → стало | синдарин: было → стало |
|---|---|---|
| страниц правил | 139 (+38 чужих) → **251** | 115 (+24 чужих) → **303** |
| записей правил | 861 (496 различных) → **782 подформулы** | 570 (345 различных) → **868 подформул** |
| засвидетельствованных дериваций | склейка примеров по страницам → **2556** из XML (194 отвергнуты Толкином) | → **2847** (186) |
| проверка формул | правило «воспроизведено», если сработал хоть один пример | воспроизводится **94,1%** шагов | **94,7%** шагов |
| рёбер графа | 391 → **606** (112 условных) | 234 → **575** (98 условных) |
| цепочек | 216 (C 38 · D 8 · U 170) → **344** (A 83 · B 63 · C 2 · D 196) | 114 (C 11 · D 10 · U 93) → **332** (A 123 · B 81 · C 1 · D 127) |
| отброшено по хронологии Eldamo | не проверялось → 64 пути | не проверялось → 101 путь |

Каждая прежняя запись своей ветви есть и в новом корпусе — 728 из 730 у квенья и 451 из 461 у
синдарина. Остальные 12 записей — подформулы трёх правил, которые Толкин удалил (`mark="-"`), и они
исключены намеренно: `✶ [ɣ] became [h] before voiceless consonants`, `ON. initial [s] unvoiced following
[l], [r]`, `ON. [ei], [ou] became [oi], [ū]`.

Рёбер, которые были только в старом графе: 43 у квенья, 31 у синдарина. Это рёбра из чужих и
удалённых правил, а также старые узлы со знаками ударения и краткости (`ˌau`, `ŭ`), которые теперь
слиты с обычными (`au`, `u`). Цепочек только в старом корпусе: 51 и 21 — прошедшие через такие рёбра
или противоречащие хронологии Eldamo.

## Смысл оценок изменился

Прежние оценки C/D/U опирались на поиск примеров на страницах правил и их склейку по общим статьям.
Новые основаны на засвидетельствованных деривациях Eldamo:

- **A** — шаги применены в этом порядке в одной деривации;
- **B** — у шагов есть примеры, порядок подтверждён ступенью языка или порядком Eldamo;
- **C** — примеры есть, порядок не установлен;
- **D** — у какого-то шага нет примеров.

Цепочки, которым противоречит порядок Eldamo, больше не строятся. Например, прежние `QUENYA18 gj → dj
→ lj` и `QUENYA127 ntr → ns → ss`, где второе правило по Eldamo старше первого.

## Источник

Вместо архива всего сайта (81 МБ в четырёх частях) хранится только `eldamo-data.xml` в xz (4 МБ) с
контрольными суммами исходного релиза. Ценное из прежних этапов сохранено в `docs/legacy/`.
