# Eldamo — канонический двуязычный фонетический атлас (без исторических архивов)

В проекте **нет каталога `archive/`, нет старых отдельных приложений и нет зависимостей от старых CSV/GraphML**.

Единственный первичный источник: `source/eldamo-0.8.13.zip`. Quenya и Sindarin извлекаются, проверяются и обрабатываются **одними и теми же** модулями `shared/` с разными явными наборами языков/периодов в `shared/extract.py`. Ни одна старинная формула не добавляется из независимого CSV.

Полная сборка: `python scripts/build_release.py`. Приёмка: `python tests/test_branch_reorganization.py` (также выполняется сборщиком). Автономный интерактивный атлас: `app/index.html`; представления всего канонического корпуса: `exports/canonical.json`, `atlas.md`, `atlas.graphml`, `corpus.html`.

**Ограничения:** правила со сложными контекстами хранятся отдельно и не превращаются в необоснованные атомарные стрелки. Структурные цепочки — не доказанные истории слов. Старые критические цепочки, 123 расширенные квенийские формы и старый независимый GraphML в этот дистрибутив **не включены**; часть не эквивалентна каноническому корпусу, поэтому их нельзя считать автоматически подтверждёнными. Анализ расхождений см. `reports/legacy_method_decisions.md` и `reports/old_vs_direct_source_audit.json`.
