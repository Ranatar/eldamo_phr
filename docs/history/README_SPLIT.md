# Eldamo: источник разделён на части

Исходный файл `source/eldamo-0.8.13.zip` не входит в новый проектный архив. Его байты разделены без перепаковки на файлы внутри `source/eldamo-0.8.13.parts/`, каждый не больше **24 000 000 байт** (меньше 25 МБ в обеих распространённых трактовках).

Восстановление: `python scripts/restore_eldamo.py`. Скрипт проверяет SHA-256 каждой части, SHA-256 целого ZIP, размер и CRC всех файлов внутри ZIP. Повторная сборка: `python scripts/build_release.py`; она автоматически восстановит исходный архив.

`python scripts/restore_eldamo.py --verify-only` дополнительно удалит восстановленный исходный ZIP после проверки. Нельзя запускать полный конвейер без возможности восстановить оригинал. `scripts/package_release.py` исключает восстановленный ZIP из дистрибутива во избежание дублирования.

Это **разбиение по байтам**, а не четыре независимо открываемых ZIP-архива: части необходимо соединять в указанном порядке.
