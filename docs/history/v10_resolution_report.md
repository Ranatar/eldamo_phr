# Контроль исключённых вариантов и последовательного исполнения контекстных формул

Данные: исключительно канонические записи и примеры в составе Eldamo 0.8.13, сохранённый аудит v9.

## Старые варианты

- `no_explicit_formula_in_legacy_record`: 130
- `not_verifiable_from_source`: 15
- `formula_present_without_exact_example`: 31
- `exact_source_examples_reproduced_not_automatically_admitted`: 56
- `source_examples_incompletely_reproduced`: 21

Наличие примеров собственной формулы не устанавливает её место в истории Quenya; такие варианты оставлены в индивидуальном реестре, а не автоматически добавлены в граф.

## Два последовательных контекстных правила по засвидетельствованным словоформам

- quenya: 139 правил, 170 совпадений соседних форм, из них 50 с одинаковой библиографической меткой.
- sindarin: 150 правил, 276 совпадений соседних форм, из них 116 с одинаковой библиографической меткой.

Даже совпадение библиографической метки НЕ устанавливает тождество этимологической статьи, историческую последовательность и совместимость редакции. Все кандидаты хранятся без повышения оценок.

## Ограничения

Скрипт проверяет только записанные в Eldamo пары словоформ при точном совпадении формул. Применение произвольного контекстного закона к новой словоформе может оставаться неподдержанным. Этот отчёт не подтверждает полную семантику всех 289 неатомарных правил.
