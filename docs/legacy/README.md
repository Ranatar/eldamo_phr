# Наследие прежних этапов

Материалы, сделанные до перехода на `eldamo-data.xml` (23–25.10.2026). Сохранены без изменений как
исследовательский архив; сборка их не читает, и в канонический корпус они не входят. Прежние README и
текстовые отчёты этапов v7–v10 — в `docs/history/`.

Многое из этого теперь проверяется автоматически: засвидетельствованные деривации Eldamo заменили
склейку примеров по страницам правил, `order` и `<before>` — ручной поиск хронологических указаний.
Ручную работу — текстовый разбор цепочек, фрагменты пояснений о хронологии — новая сборка не повторяет.
Ссылки на правила в этих файлах ведут на eldamo.org и остаются рабочими; нумерация цепочек и оценки
(A/B/C/D/U/X) принадлежат прежним методам и с нынешними оценками A–D не совпадают.

## 1. Исследовательский пакет по квенья

`1-quenya-research/` — первый этап: только квенья, правила с HTML-карточек фонем, граф из 516 переходов
и 101 «составная линия», затем всё более строгие проверки.

| Файл | Что это |
|---|---|
| `reports/eldamo_critical_101_atlas.md`, `.csv` | критический атлас 101 цепочки со шкалой A–X и обоснованием каждой (итог: A 0, B 6, C 14, D 33, U 48) |
| `reports/eldamo_strict_chain_report.md`, `evidence/eldamo_strict_chain_evidence.csv` | «строгие цепочки» по шести условиям (та же формула, общие промежуточные формы, общая статья, общий источник, нет удалённых разделов, правильный каталог): 19 когерентных |
| `reports/eldamo_textual_chain_report.md`, `evidence/eldamo_textual_chain_assessment.csv` | ручная интерпретация пояснений Eldamo к этим 19 цепочкам: совместимость, диалектные ограничения, что требует первичного текста |
| `evidence/eldamo_exact_word_joins.csv` | 1159 точных соединений словоформ между шагами |
| `evidence/eldamo_order_and_context_clues.csv` | 301 фрагмент пояснений об относительной хронологии и контекстах |
| `evidence/eldamo_rule_commentary_audit.csv` | разбор пояснений к правилам |
| `evidence/eldamo_sound_graph.graphml`, `eldamo_sound_edges.csv` | первый граф: 516 переходов |
| `engine/eldamo_interpreter_v2.py`, `_v3.py`, `eldamo_context_interpreter.py` | прежние интерпретаторы формул (v3 использовался до перехода на XML) |
| `catalog/eldamo_six_languages_ipa_catalog.md` | каталог шести языков в МФА |

## 2. Атлас 139 цепочек

`2-atlas-139/` — атлас из 101 + 38 оценённых цепочек с деревьями развития и происхождения.
`README_ATLAS.md` — описание того атласа; `eldamo_38_chain_assessment.*` — оценки 38 добавленных цепочек
(11 D, 27 U).
