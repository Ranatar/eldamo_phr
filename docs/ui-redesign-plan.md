# Переделка интерфейса: слово в центре

Сейчас атлас устроен как справочник по фонетике. Первым делом нужно выбрать ветвь. Затем идут пять равноправных
панелей одна под другой: «Пути между звуками», «Словотворчество», «Реконструкция», «Атлас цепочек»,
«Деривации Eldamo». Всё, что делалось до версии 2.3, было подготовкой к работе со словом: восстановить его
форму для другого периода, построить новое. Интерфейс должен это отражать. Работа со словом — главное,
фонетический справочник — опора для проверки, свёрнутая по умолчанию.

Документ описывает, что мешает сейчас, два варианта новой структуры, рекомендуемый вариант, схему адресов
и план работ. Вопросы, где нужно решение автора, собраны в §8.

## 1. Что мешает сейчас

**Порядок и вес.** Главная страница — карточки ветвей со статистикой правил и цепочек. Под шапкой первым
идёт выбор звуков по сетке МФА. До реконструкции надо пролистать два экрана.

**Ветвь и концепция заданы глобально, в шапке.** Это удобно справочнику: граф, цепочки и деривации
строятся для одной ветви. Инструментам со словом глобальный выбор мешает:
- реконструкция по природе пересекает ветви и концепции — когнат S. → Q., ᴹQ. → Q.;
- поиск слова в реконструкции ищет только в ветви из шапки. Чтобы найти S. galadh, сначала нужно
  переключить шапку на синдарин;
- в словотворчестве концепция из шапки фильтрует найденные слова. Это не очевидно: «поздняя» в шапке
  молча прячет все слова ᴹQ.

**Два инструмента не связаны друг с другом.** В каждом свой поиск слова и свой выбор. Результат
реконструкции нельзя взять элементом сложения. Сложение нельзя отправить в реконструкцию («какой была бы
эта форма в синдарине»). Деривация из справочника не открывается в инструментах.

**Правила в ответах уводят на Eldamo.** Шаг «medial [j] became [i]» ведёт на сайт Eldamo, хотя в самом
атласе есть правила звука, их примеры и цепочки.

**Справочник рисуется сразу целиком.** При открытии ветви строятся граф путей, цепочки и деривации.
Данные справочника (3,2 МБ JSON) разбираются при загрузке, даже если человек пришёл только реконструировать.

**Мелочи, замеченные при обзоре:**
- фонетическая запись в ответах показывает знак краткости: S. galadh → Q. «aldă» вместо alda;
- промежуточные стадии не переводятся в написание, видна только фонетика Eldamo;
- список правил в ответе плоский, по нему не видно, где кончается одна стадия и начинается следующая.

## 2. Вариант А: два инструмента главные, справочник свёрнут

Это предложение автора, почти дословно.

```
┌ шапка: Eldamo · тема ─────────────────────────────────────────────┐
│ [ Реконструкция ] [ Словотворчество ]          ← вкладки           │
│ ┌──────────────────────────────────────────────────────────────┐   │
│ │ инструмент: поиск слова по обеим ветвям, периоды, результат  │   │
│ └──────────────────────────────────────────────────────────────┘   │
│ ▸ Справочник по фонетике (свёрнут)                                │
│     ветвь [квенья ▾] концепция [поздняя ▾]                        │
│     ▸ Пути между звуками  ▸ Атлас цепочек  ▸ Деривации Eldamo     │
└───────────────────────────────────────────────────────────────────┘
```

- Выбор ветви и концепции переезжает в справочник и действует только на него.
- Инструменты ищут слово по обеим ветвям и всем концепциям, с маркером языка (Q., S., ᴹQ., N., ᴱQ., G.).
- Карточки ветвей на входе пропадают: вход сразу открывает реконструкцию.

Плюсы: небольшая переделка — перестановка панелей, вкладки, перенос селекторов. Минусы: два инструмента
по-прежнему живут отдельно, слово выбирается в каждом заново.

## 3. Вариант Б: слово в центре

Главный объект страницы — **слово**: его выбирают один раз, а инструменты работают с ним.

```
┌ шапка: Eldamo · [ найти слово: lindë            ] · тема ───────────┐
│ ┌ Q. lindë «song, air, tune» ─ статья Eldamo ─ корень ✶LIN² ───────┐ │
│ │ Панорама периодов                                                 │ │
│ │            праформа     промежуточная      язык                   │ │
│ │ поздняя Q. ✶lindē ●     AQ. lindē ○         Q. lindë ●            │ │
│ │ поздняя S. ✶lindē ○     AT./OS. …  ○         S. linn ○ (glinn)     │ │
│ │ средняя    ᴹ✶lindē ●    …                   ᴹQ. lindë ○ · N. glinn ●│ │
│ │ ранняя     …                                                      │ │
│ │ ● засвидетельствовано  ○ восстановлено  ◇ неологизм               │ │
│ └───────────────────────────────────────────────────────────────────┘ │
│ [ Реконструкция ] [ Сложение ] [ Аффикс ]   ← действия со словом     │
│   выбранная клетка панорамы раскрывается: варианты, маршрут, правила   │
│ ▸ Справочник по фонетике (свёрнут)                                    │
└───────────────────────────────────────────────────────────────────────┘
```

**Карточка слова.** Форма, язык, значение, ссылка на Eldamo, корень, праформа Eldamo, связи
`combine`/`deprecated`/`cognate`, засвидетельствованные деривации. Всё это уже есть в лексиконе.

**Панорама периодов** — главное новшество. Реконструкция сразу во все периоды, таблицей: ветвь × концепция ×
стадия, до 17 клеток (схема выше условна: формы в ней для примера).
- Засвидетельствованные формы видны рядом с восстановленными. Пустые клетки показывают, где у Толкина
  слова нет.
- В клетке — первый вариант и его пометка. Щелчок раскрывает клетку: все варианты, маршрут, правила по
  стадиям.
- Расчёт — по клетке за раз, по мере готовности. По замерам JS-движка на сложное слово уходит 0,1–0,3 с
  на клетку, так что вся панорама займёт 1–3 с. Если окажется медленно, расчёт переносится в Web Worker.

**Действия со словом:**
- *Реконструкция* — то же, что сейчас, но слово уже выбрано, а исходный период подставлен из его языка;
- *Сложение* — слово становится первым элементом, второй ищется рядом;
- *Аффикс* — те же поля, но второй элемент ищется среди суффиксов и приставок.

Любой ответ — восстановленная форма, вариант сложения — можно сделать текущим словом кнопкой «работать
с этой формой». Так, например, сложение строится на ᴹQ., а затем его переносят в позднюю квенья.

Плюсы: одно слово на всё, панорама отвечает на вопрос «какой была эта форма» одним взглядом, инструменты
связаны. Минусы: больше работы. Кроме того, у формы, введённой вручную (не из лексикона), нет карточки,
и карточка будет усечённой.

## 4. Рекомендация

**Вариант Б, собранный поверх А.** Сначала — перестановка из варианта А: вкладки, справочник свёрнут,
ветвь в справочнике, поиск по обеим ветвям. Это само по себе исправляет главное неудобство. Затем — общий
выбор слова, карточка и панорама. На каждом шаге атлас остаётся рабочим, а тесты обновляются по частям.

Дополнительно к варианту Б:

1. **Ответ по стадиям.** Правила в ответе группируются по стадиям, у каждой стадии — промежуточная форма в
   фонетике и в написании:
   `✶delya → AT. delja → OS. deil → S. dail`, под стрелкой — правила этой стадии.
2. **Правила ведут в справочник.** Название правила в ответе раскрывает справочник на правиле: формула,
   примеры, цепочки. Ссылка на Eldamo остаётся рядом значком.
3. **Из деривации — в инструменты.** У каждой деривации в справочнике кнопка «открыть слово»: карточка и
   панорама.
4. **Ленивый справочник.** Данные справочника разбираются и рисуются при первом раскрытии раздела. Атлас
   открывается быстрее, а размер файла не меняется.
5. **Пояснения к пометкам** во всплывающих подсказках вместо длинного абзаца под ответом. Короткая
   легенда: «● засвидетельствовано, ○ восстановлено законами, ◇ неологизм, ⚠ нетипично для языка».
6. **Недавние слова** — пять последних в поле поиска. Хранятся в localStorage с защитой try/catch.
7. **Название.** «Фонетический атлас» описывает справочник, а не главное. Варианты: «Eldamo — мастерская
   слова», «Эльдамо: реконструкция и словотворчество». Решать автору (§8).

## 5. Адреса

Сейчас: `#quenya?era=late&from=b&to=v` — ветвь, концепция и два звука справочника.

Новая схема:

| адрес | что открывает |
|---|---|
| `#` | инструменты без слова: поле поиска и примеры |
| `#w=403686503` | карточку и панораму слова lindë |
| `#w=403686503&dst=sindarin/late/3` | то же, с реконструкцией в S. |
| `#w=403686503&tab=compose` | слово как первый элемент сложения |
| `#f=linde&in=quenya/late/2` | форму без статьи, введённую вручную |
| `#ref=paths&b=quenya&era=late&from=b&to=v` | справочник, раздел «Пути», раскрыт |
| `#ref=chains&b=sindarin` / `#ref=derivations&q=galadh` | другие разделы справочника |

Старые адреса (`#quenya?…`) переводятся в `#ref=paths&b=quenya…`, так что прежние ссылки не ломаются.
Кнопка «назад» браузера работает так же, как сейчас.

## 6. Что меняется в коде

| файл | изменение |
|---|---|
| `app/template.html` | новый порядок: шапка с поиском, карточка, панорама, вкладки действий, `<details>` справочника; селекторы ветви и концепции переезжают в справочник |
| `app/runtime.js` | справочник: ленивая инициализация, свой выбор ветви и концепции, новые адреса и перевод старых |
| `app/wordform_ui.js`, `app/reconstruct_ui.js` | общий модуль выбора слова (`word_ui.js`), поиск по обеим ветвям; панели принимают слово извне |
| новый `app/word_ui.js` | карточка, панорама, общий поиск, недавние слова, адреса `#w=` |
| `app/wordform.js` | без изменений в движке; функция `panorama(engines, word)` — последовательность вызовов `reconstruct` |
| `app/styles.css` | вкладки, таблица панорамы, свёрнутый справочник, мобильная вёрстка: панорама превращается в список по ветвям |
| `tests/test_browser.py` | 12 тестов: проверки справочника переходят на `#ref=…`, новые тесты на панораму, переходы между инструментами, перевод старых адресов |

Python-часть не меняется, кроме `shared/app.py` (новый модуль в шаблоне). Движок и паритет JS с Python
тоже не затрагиваются.

## 7. План работ

1. **Перестановка (вариант А).** Вкладки «Реконструкция» и «Словотворчество» наверху. Справочник в
   `<details>` со своей ветвью и концепцией. Поиск слова по обеим ветвям и всем концепциям. Входная
   страница — инструменты. Перевод старых адресов.
2. **Общее слово.** `word_ui.js`: один поиск, карточка, адреса `#w=`. Обе вкладки работают с выбранным
   словом. Кнопка «работать с этой формой» у ответов.
3. **Панорама периодов.** Таблица по клеткам с постепенным расчётом и раскрытием клетки.
4. **Ответ по стадиям и правила в справочник.** Группировка правил, написание промежуточных форм,
   переход от правила к его разделу в справочнике, кнопка «открыть слово» в деривациях.
5. **Ленивый справочник и мелочи.** Отложенный разбор данных, подсказки к пометкам, недавние слова,
   знаки краткости в ответах.
6. **Документация.** README («Что умеет атлас»), `docs/reconstruction.md`, `docs/word-formation.md`
   (как теперь пользоваться), CHANGELOG.

Каждый этап заканчивается полной сборкой с браузерными тестами.

## 8. Нужны решения автора

1. **Вариант:** А, Б или Б поверх А (рекомендация — последнее).
2. **Название атласа:** оставить «фонетический атлас» или переименовать (варианты в §4.7).
3. **Справочник:** один свёрнутый блок с тремя разделами или три отдельных свёрнутых раздела в одном
   ряду.
4. **Неологизмы в поиске:** сейчас скрыты флажком. В общем поиске показывать их всегда с пометкой или
   по-прежнему по флажку.

## 9. Решения и состояние (версия 3.0)

Автор выбрал вариант **Б поверх А**; проект переименован в **Quettamin** («кузница слова», из слов Eldamo
разных периодов); справочник — три отдельных свёрнутых раздела с кнопкой «развернуть / свернуть всё»;
неологизмы в общем поиске — по отдельному переключателю в шапке.

Сделано всё из §4 и §7, кроме мелочей, отмеченных ниже.

| что | как сделано |
|---|---|
| вход | поиск слова в шапке; без слова — вступление с примерами и недавними словами |
| карточка | язык, значение, основа, корень, праформа, связи Eldamo со ссылками, переход к деривациям слова |
| панорама | до 17 клеток, считаются по одной; щелчок открывает реконструкцию с этим периодом |
| вкладки | «Реконструкция» (периоды обеих ветвей в одном списке) и «Словотворчество» (своя ветвь и концепция; выбранное слово — первый элемент) |
| ответ | правила сгруппированы по стадиям; правило открывается в справочнике, ↗ — статья Eldamo; «работать с этой формой» |
| справочник | `app/runtime.js`: данные разбираются при первом раскрытии; свой выбор ветви и концепции; вид одного правила; «открыть слово» у дериваций; фильтр `w:<id>` |
| адреса | `#w=…&dst=…&tab=…`, `#f=…&in=…`, `#ref=paths|rule|chains|derivations&b=…&era=…` |

Отличия от §5: целевой период реконструкции записывается как `dst`, а не `to` (`to` занят звуком
справочника); второй элемент сложения и стадия образования в адрес не пишутся.
