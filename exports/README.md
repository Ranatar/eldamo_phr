# Экспорт

Файлы создаёт `python scripts/build.py`; в git они не хранятся.

- `canonical.json` — всё содержимое обеих ветвей одним файлом: правила, подформулы, деривации с
  проверкой шагов, фонемы, рёбра графа, цепочки, сводка. Формат `eldamo-phonetic-atlas/2`.
- `atlas.graphml` — граф звуковых переходов для Gephi, yEd и т. п.: по графу на ветвь и концепцию, у рёбер
  язык, ступень, позиция, правила, условие, число примеров.
