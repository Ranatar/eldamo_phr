# Сквозные линии звукопреобразований Eldamo 0.8.13 — первый проверяемый прототип

## Назначение

Это **машинно построенный список кандидатов на исторические линии**, а не реконструкция автоматически подтверждённых этимологий. Из шести звуковых каталогов извлечены ориентированные переходы, для которых обе стороны формулы являются явно записанными линейными звуковыми последовательностями. Этимологическая проверка по конкретным словам ещё не выполнена.

## Ключевые ограничения

- Направление восстановлено по обозначению Eldamo: `A < B` даёт `B → A`, `A > B` даёт `A → B`.
- Разделены **поздняя концепция** (`✶`, `AQ.`, `Q.`) и **средняя концепция** (`ᴹ✶`, `ᴹAQ.`, `ᴹQ.`); смешивать их запрещено.
- Задаётся упрощённый порядок стадий `Primitive → Ancient Quenya → Quenya`. Это порядок *ярлыков языковой ступени*, а не гарантированная датировка каждого изменения.
- В CSV кандидатов следующая стрелка допускается, только если её источник буквально совпадает с результатом предыдущей и стадия **строго выше**. Поэтому это намеренно неполный поиск: внутристадийные цепочки пропускаются.
- Формулы со скобками, подстановками, перечислениями и прочими неатомарными обозначениями вынесены из автоматического соединения. Границы слова (`-`) при сопоставлении не отбрасываются.
- Фонетические окружения и исключения из текстов правил полностью **не формализованы**. Каждая найденная составная линия — гипотеза до проверки по этимологическим статьям и контекстам.
- Одинаковые переходы с различными ссылками на правила оставлены как независимые варианты.

## Охват и результаты

- Исходные карточки: **242**, отобранные строки: **1642**.
- Нормализованные ориентированные записи (с уникальным правилом и эпохой): **516**.
- Не вошли в строгую нормализацию: **294** строк; причины: no change — 46, non-atomic / context-sensitive notation — 248.
- Формально составные линии из двух или трёх переходов: **101** (включая варианты по ссылкам на правила).

## Файлы результатов

- [`eldamo_sound_edges.csv`](eldamo_sound_edges.csv) — полный список строго нормализованных рёбер с маркерами, страницами и источниками.

- Скрипт `build_eldamo_paths.py` воспроизводит обработку из архива в той же папке.

## Следующий методологический этап

Для каждой линии нужно проверить исходные формулировки правил (позиционные и морфонологические условия), а затем найти реальные этимологические цепи конкретных слов в Eldamo. Только после этого можно повышать статус «формально составима» до «текстологически подтверждена».
